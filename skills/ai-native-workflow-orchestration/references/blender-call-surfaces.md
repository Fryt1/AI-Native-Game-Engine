# Blender Call Surfaces

## Blender CLI + Python

Use for background, batch, deterministic, repeatable file processing, automatic
validation, rendering, and baking.

## Blender Add-on

Use for the current Blender session, Scene, Selection, Active Object, Mode,
interactive panels, and user confirmation.

The AssetsBridge Blender Add-on is a concrete Bridge Connector implementation;
it is not Blender itself and does not replace the Blender Executor seam.

## Version note

The repository's own minimal AI Native Add-on operations are tested with
Blender 4.2.0. The current upstream AssetsBridge Blender Add-on declares
Blender 5.0+ and should be treated as a separate external dependency.
