# Stage Kind: Planning

Use for selecting a path, preparing a repair, choosing a format, or producing an
implementation or optimization plan.

## Execution checklist knowledge

- collect goals, constraints, preservation, and risk policy
- inspect current environment and object state
- query relevant Toolsets and Tool schemas
- form candidate paths and reject infeasible paths
- identify dependencies, side effects, rollback, and acceptance methods

## Acceptance checklist knowledge

- every user goal and constraint is covered
- selected Tools exist and required inputs can be obtained
- dependencies and order are valid
- destructive risks and recovery are explicit
- every future change Stage has a feasible acceptance method
- the output is actionable rather than only descriptive
