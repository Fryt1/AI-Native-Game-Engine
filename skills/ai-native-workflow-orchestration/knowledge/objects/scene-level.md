# Object Knowledge: Scene and Level

## Before execution

Inspect hierarchy, Transform, parent relationships, cameras, lights, Data
Layers, World Partition, current map/scene, and ownership of target objects.

## After execution

Check object existence, hierarchy, Transform, parents, cameras/lights, Data
Layers, duplicate objects, missing references, current loaded map, and save
state.

## Evidence

Use object/Actor listings, path identities, Level/Scene metadata, and read-back
queries.
