# Object Knowledge: Project, Runtime, and Performance

## Before execution

Inspect project settings, plugins, engine/tool versions, target platform, build
conditions, runtime environment, and performance baseline.

## After execution

Check persisted configuration, plugin state, build result, target-platform
runtime, logs, regressions, and measured performance against the baseline.

## Evidence

Use configuration reads, build artifacts, runtime logs, profiler captures, and
repeatable measurements.
