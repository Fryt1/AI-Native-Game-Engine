# Object Knowledge: Geometry

## Before execution

Inspect object type, topology, units, axes, normals, UVs, material slots, LODs,
and collision requirements.

## After execution

Check vertex/triangle facts when relevant, topology, normals, UVs, material slot
order, LODs, collision, scale, orientation, and accidental extra geometry.

## Evidence

Prefer structured mesh statistics, asset metadata, import logs, and independent
source/target reads over screenshots.
