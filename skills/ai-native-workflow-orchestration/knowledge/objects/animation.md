# Object Knowledge: Animation

## Before execution

Inspect animation count, names, frame rate, frame range, duration, tracks,
curves, Root Motion, target Skeleton, and retarget policy.

## After execution

Check count/names, frame rate, duration, tracks, curves, Root Motion, Skeleton
binding, and retarget result.

## Evidence

Use structured clip inventories, curve/track metadata, Skeleton references, and
runtime playback evidence when the task requires it.
