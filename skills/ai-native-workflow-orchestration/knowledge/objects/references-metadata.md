# Object Knowledge: References and Metadata

## Before execution

Inspect asset paths, names, dependency direction, source/provenance, versions,
identifiers, and reference policy.

## After execution

Check path/name rules, reference validity, orphaned or cyclic references,
provenance, version, dependency completeness, and identity preservation.

## Evidence

Use dependency graphs, manifests, stable IDs, source-control or package metadata,
and target-system reference queries.
